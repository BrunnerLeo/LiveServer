# Code of Conduct

## Erwartung

Beiträge sollen sachlich, respektvoll und lösungsorientiert sein. Kritik ist willkommen, wenn sie konkret und überprüfbar ist.

## Nicht akzeptabel

- persönliche Angriffe
- diskriminierende Sprache
- Veröffentlichung privater Daten
- absichtliches Stören von Diskussionen oder Projektarbeit
- Sicherheitsdetails öffentlich posten, bevor Maintainer reagieren konnten

## Durchsetzung

Maintainer können Beiträge schließen, bearbeiten oder entfernen, wenn sie gegen diese Regeln verstoßen. Schwere oder wiederholte Verstöße können zum Ausschluss aus der Projektarbeit führen.
